Get started in 5 minutes
1

Install the gateway

pip install "airiskguard[server]"
2

Validate your license key

airiskguard-gateway license YOUR-LICENSE-KEY
Should print: License valid.
3

Install the CA certificate and start the proxy

airiskguard-gateway install-cert
airiskguard-gateway start
4

Start the policy server with your license key

AIRISKGUARD_LICENSE=YOUR_KEY docker compose up -d
Clone first: git clone https://github.com/gobeyondfj-cmd/airiskguard-gateway
5

Open the cost dashboard

open http://localhost:8000/dashboard
6

Set these in your shell

# Claude Code
export ANTHROPIC_BASE_URL=http://127.0.0.1:8080/anthropic
export ANTHROPIC_API_KEY=gateway-managed

# Codex CLI / OpenAI SDK
export OPENAI_BASE_URL=http://127.0.0.1:8080/openai
export OPENAI_API_KEY=gateway-managed
