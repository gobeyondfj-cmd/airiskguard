⬇ Step 1 — Install the gateway

1

Install the gateway package

pip install airiskguard-gateway
2

Generate and install the CA certificate

airiskguard-gateway install-cert
This lets the proxy intercept HTTPS traffic. Runs once.
3

Start the gateway

airiskguard-gateway start
4

Set these in your shell (add to ~/.zshrc or ~/.bashrc)

export HTTPS_PROXY=http://127.0.0.1:8080
export NODE_EXTRA_CA_CERTS=~/.config/airiskguard-gateway/mitmproxy-ca-cert.pem
NODE_EXTRA_CA_CERTS is required for Claude Code and other Node-based AI tools.

🖥 Step 2 — Start the Team policy server

1

Install with server extras

pip install "airiskguard-gateway[server]"
2

Start with Docker Compose (PostgreSQL + policy server)

git clone https://github.com/gobeyondfj-cmd/airiskguard-gateway
cd airiskguard-gateway
docker compose up -d
3

Open the dashboard

open http://localhost:8000/dashboard
4

Connect the gateway to your policy server (in config.yaml)

policy_server:
  url: "http://your-server:8000"
  api_key: "your-team-api-key"

⚡ Step 3 — Add routing rules (optional)

1

Edit ~/.config/airiskguard-gateway/config.yaml

routing:
  rules:
    # Route PII to your internal model
    - match: contains_pii
      action: route_to
      destination: internal_llm
    # Downgrade gpt-4 requests to cheaper model
    - match: model_pattern
      model_pattern: "gpt-4*"
      action: route_to
      destination: gpt_4o_mini
  destinations:
    internal_llm:
      provider: ollama
      base_url: http://localhost:11434
      model: llama3.2
    gpt_4o_mini:
      provider: openai
      model: gpt-4o-mini
