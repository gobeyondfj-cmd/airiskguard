// The Problem

Your team is burning money on AI. You can't see it happening.

Every developer makes hundreds of AI API calls a day. No routing. No visibility. No control over what gets sent where.

Claude Sonnet-5 for everything

60% of your team's queries are simple Q&A, autocomplete, or quick lookups. You're paying $3/M tokens when $0.30/M on DeepSeek Flash does the same job.

PII and secrets in prompts

Developers paste customer SSNs, API keys, and credit card data into AI tools daily. None of it is caught before it reaches an external API.

Zero cost visibility

You get one monthly invoice from Anthropic or OpenAI. You have no idea which developer, which tool, or which model is responsible for the bill.

No routing control

Financial records, health data, client files — they should never leave the machine. Right now they do. No one knows, and there's no audit trail.

// Configuration

Smart routing in plain YAML

Define rules in config.yaml. Restart the gateway. Done. No code changes needed on any client.

config.yaml
routing: sticky_sessions: true # same conversation → same model rules: - match: contains_pii # SSN, email, credit card action: route_to destination: local_ollama # never leaves the machine - match: task_type task_type: simple_qa # "what is", "define", etc. action: route_to destination: deepseek_flash # $0.30/M vs $3.00/M - match: contains_financial_data action: block # hard block - match: model_pattern model_pattern: "gpt-5.6-sol" action: route_to destination: gpt_luna # $1/M instead of $5/M destinations: local_ollama: { provider: ollama, model: llama3.3:70b } deepseek_flash: { provider: deepseek, model: deepseek-v4-flash } gpt_luna: { provider: openai, model: gpt-5.6-luna }
// Features

Four things that actually matter

No bloat. The 20% that covers 80% of what teams using AI at scale need.

⚡

Smart Routing

Route by PII, task type, language, or model pattern. Simple Q&A goes to DeepSeek Flash ($0.30/M). Sensitive content stays on local Ollama. Session stickiness keeps conversations on the same model throughout.

💰

Cost Dashboard

Spend by model, by developer, by day. Set per-provider budget limits. Get Slack alerts before you hit the ceiling. See what routing actually saved you versus sending everything to Claude Sonnet-5.

🔒

Secrets + PII Detection

API keys, SSNs, credit cards, bank account numbers, and financial data are blocked or redacted before leaving the machine. Outbound and inbound scan — catches injected content in responses too.

✅

Model Allowlist

10 built-in providers, 50+ models. Enable or disable per provider. Developers get gateway keys — nobody ever sees the real API keys. Anything outside the allowlist is blocked at the proxy.

// Setup

Up and running in 3 steps

No CA certificate. No code changes. Just a proxy and one env var.

1

Install and start

# install
pip install airiskguard

# start the gateway on :8080
airiskguard-gateway start
2

Point your tool at the gateway

# Claude Code / any Anthropic SDK tool
export ANTHROPIC_BASE_URL=http://127.0.0.1:8080/anthropic
export ANTHROPIC_API_KEY=gw-your-key

# Cursor / Copilot / OpenAI SDK
export OPENAI_BASE_URL=http://127.0.0.1:8080/openai
export OPENAI_API_KEY=gw-your-key
3

Check key status

airiskguard-gateway keys

KEY           USER                STATUS
gw-abc123    john@company.com    active
gw-def456    jane@company.com    active
gw-ghi789    bob@company.com     revoked
